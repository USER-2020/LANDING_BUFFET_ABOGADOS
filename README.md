# Nexo Legal

Landing de servicios de inmigración en español, construida con React y Vite. Marca conceptual, diseño responsive, menú móvil, preguntas desplegables y formulario con validación y descarga local del resumen.

## Desarrollo

```sh
npm install
npm run dev
```

## Producción

```sh
npm run build
npm run preview
```

El formulario es una demostración: no envía ni almacena datos. Antes de publicar, conectar un backend de contacto, configurar la política de privacidad y sustituir la marca y el contenido por los datos reales del despacho y sus jurisdicciones. No se incluyen testimonios ni resultados inventados.

Las fotografías se cargan desde Unsplash y las fuentes desde Google Fonts; requieren conexión a internet. Contenido y componentes en `src/main.jsx`, estilos en `src/styles.css`.
